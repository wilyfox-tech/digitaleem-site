Digitaleem WordPress theme

Install
1. In WordPress, go to Appearance > Themes > Add New Theme > Upload Theme, choose digitaleem.zip and click Install Now.
2. Click Activate. The theme creates every page of the site, sets the home page and turns on clean links (/students/).
3. Go to Settings > Digitaleem and enter the email address that should receive enquiries, and the contact details for the footer.
4. Install an SMTP plugin (for example WP Mail SMTP) so enquiry emails are delivered reliably. Enquiries are always saved under Enquiries in the dashboard, even if email fails.

Everyday use
- Opportunities: Opportunities > Add opening. Fill in the details and publish. An opening disappears from the site after its "Apply by" date.
- Enquiries: every form on the site saves here, with all answers, and is emailed to the address in Settings > Digitaleem.
- Pages: each page is a single HTML block in the editor. Text can be edited there. Keep the HTML tags as they are.

Updating the theme
Upload the new zip (WordPress offers to replace the current version). Then Settings > Digitaleem > "Update pages from the theme" brings the pages in line with the new version. It replaces edits made to those pages in WordPress.
